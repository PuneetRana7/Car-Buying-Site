# Range Rover Car-Buying Website

## About the Project

A simple car-buying website designed using HTML and CSS. It showcases Range Rover models, luxury features, special offers, and car prices.

## Features

* Luxury Range Rover landing page
* Navigation bar with six links
* Car categories and special offers
* Eight car cards with images and discount labels
* Original and discounted prices
* Why Choose Range Rover section
* Test drive booking button
* Footer with useful links

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Positioning and box shadows

## Project Files

* `index.html` — Website structure and content
* `style.css` — Website styling and layout

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Explore the website.
